# Portfolio-S

## Shyamaprasad M. S. — Data Engineer & Python Developer Portfolio

A modern, responsive, high-performance portfolio React application built with **React 19**, **Vite**, and **Tailwind CSS**.

### Key Features
- **Executive Profile & Portrait**: High-resolution showcase with natural document flow and key credentials.
- **Interactive Skills Explorer**: Real-time search and filter across 31 technical skills.
- **Airflow DAG & GCP Pipeline Simulator**: Interactive 4-stage pipeline simulator with telemetry inspector and animated execution.
- **Selected Projects**: Filterable project gallery with detailed architectural modals.
- **ATS Resume View**: Single-page recruiter-friendly view with one-click print/PDF export.
- **Interactive Inquiry Composer**: Fast direct inquiry launcher with one-click email and phone copying.
- **Dark / Light Mode**: Seamless theme toggling.

### Getting Started

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build

# Run linter
npm run lint
```
